
# Introduction

Similar to how simply typed [[lambda-calculus]] gives a computational interpretation of [[intuitionistic logic]], lambda-mu calculus gives an computational interpretation of [[classical logic]], the [[excluded middle]] and [[double negation]]. It is an extension of [[lambda-calculus]] with "continuation" capturing and passing.

The idea is that for the law of excluded middle one must prove $A \vee \neg A$. The a proof of $\neg A$ is usually thought of as a $A \to \bot$, where it takes in an element of $A$ and returns an element of the empty type $\bot$, which should be impossible. Instead to prove the LEM, it creates an element of $A \to \bot$ that is really is a continuation that "jumps" somewhere else in the program, so it has a return type of $\bot$ as in that it never returns. Where it jumps to gets provided an element of $A$, as the other half of the LEM. It can be though of that whenever an element $f : A \to \bot$ is used with an element $a : A$ as $f a$ it can take that $a$ and insert it as $inl(a)$ for $A \vee \neg A$.



# Definition

Here is simply typed from Michel Parigot. Terms in regular lambda calculus are usually generated by variables, function application, and lambda abstraction.

$$term = var | term \quad term | \lambda var . term$$

here $var$ is a countable set of variables.

$$var = x | y | z | \dots$$

Instead terms are extended by giving them to a continuation or capturing a continuation.

$$term = var | term \quad term | \lambda var . term | [covar] term | \mu covar . term$$

The covariables represent continuations and are also a countable set of names.

$$covar = \alpha | \beta | \gamma | \dots$$

The usuall rules of lambda calculus

$$\frac{\Gamma, a : A \vdash b : B}{\Gamma \vdash \lambda a . b : A \to B}$$

are instead extended to where judgments add an extra context $\Delta$ 

$$\Gamma; \Delta \vdash t : T$$

The context $\Gamma$ is the usual context of variables.

$$\Gamma = a : A, b : B, c : C, \dots$$

But in contrast the $\Delta$ is a context of covariables, where $\alpha : A$ represents a continuation that takes in type $A$.

$$\Delta = \alpha : A, \beta : B, \gamma : C, \dots$$

The usual lambda calculus rules stay the same by simply ignoring $\Delta$. For example lambda abstraction is the same.

$$\frac{\Gamma, a : A; \Delta \vdash b : B}{\Gamma ; \Delta \vdash \lambda a . b : A \to B}$$

But the calculus has some additional rules added. For example given a an element $t : A$ and a continuation $\alpha : A$ one can pass $t$ into $\alpha$ and it will jump somewhere else in the program giving $[\alpha]t : \bot$.

$$\frac{\Gamma; \Delta, \alpha : A\vdash t : A}{\Gamma; \Delta, \alpha : A \vdash [\alpha] t : \bot}$$

Additionally one can capture a continuation

$$\frac{\Gamma; \Delta, \alpha : A\vdash t : A}{\Gamma; \Delta \vdash \mu \alpha . t : A}$$

The continuation passing is represented with some additional judgmental equalities. Regular lambda calculus has $beta$-reduction and $\eta$-reduction.

$$(\lambda x . t)s \equiv t[s/x]$$

$$(\lambda x . (f x) \equiv f$$

the lambda-mu calculus also has the following judgmental equalities.


If $t$ is passed to a continuation $\alpha$ that is immediately captured then it's the same as just using $a$
$$\mu \alpha . [\alpha]t \equiv t$$

If $t$ is captured by $\beta$ that then immediately goes into $\alpha$ then $t$ might as well just pass anything it passed into $\beta$ directly into $\alpha$

$$\mu \alpha . [\alpha]t \equiv t[\alpha / \beta]$$

If $alpha$ returns a function from $t$ and is then applied to $s$ then  one can instead apply $s$ to anywhere something is passed into $\alpha$.

$$(\mu \alpha . t) s \equiv \mu \alpha . t[[\alpha](n s)/[\alpha]n]$$

# Examples

## Double negation

We want to prove $((A \to \bot) \to \bot) \to A$ for any $A$. So we can say We are given an $h : ((A \to \bot) \to \bot)$ and want to get a term of $A$. We can give $h$ a "fake" $A \to \bot$ by using a capture. 

$$k = \lambda x . [\alpha] x$$

$$\Gamma; \Delta, \alpha : A \vdash \lambda x . [\alpha] x : A \to \bot$$

So $k$ will take an $A$ and pass upwards to wherever $\alpha$ is captured by a $\mu$.

Applying $h$ to $k$ will yield a $\bot$.

$$\Gamma, h: ((A \to \bot) \to \bot); \Delta, \alpha : A \vdash h (\lambda x . [\alpha] x) : \bot$$

Now we can simply capture the $A$ that $k$ is throwing up with a $\mu$ abstraction.

$$\Gamma, h: ((A \to \bot) \to \bot); \Delta \vdash \mu \alpha . h (\lambda x . [\alpha] x) : A$$

Then do a regular lambda abstraction.

$$\Gamma; \Delta \vdash \lambda h . \mu \alpha . h (\lambda x . [\alpha] x) : ((A \to \bot) \to \bot) \to A$$

The intuition here is that any $h : ((A \to \bot) \to \bot)$ to use its input argument $A \to \bot$ must give that $A \to \bot$ a value of $A$ to get $\bot$, but we pass that $A$ into the continuation $\alpha$ that jumps back up and can then provde that $A$ for the output.

## Law of excluded middle

Intuitionistic logic can already prove $\neg \neg ( A \vee \neg A)$ so using double negation we can already get LEM. But there is a nicer way of proving it.

Let's say we have

$$\lambda x . [\alpha] (inl x)) : (A \to \bot)$$

we can then insert that onto the right side of the sum

$$inr(\lambda x . [\alpha] (inl x)) : A \vee (A \to \bot)$$

and then capture the $\alpha$

$$\mu \alpha . inr(\lambda x . [\alpha] (inl x)) : A \vee (A \to \bot)$$

The intuition here is that anything that uses the LEM must match both sides of the sum. So it first provides the right side $A \to \bot$ as a continuation, so when the proof uses that by passing an $A$ into it, it jumps back and uses that $A$ on the left side. Thus providing $A \vee (A \to \bot)$.
